So here is the flow: Base selection: after starting the game we have a random order of players. In the random order the 1st player pick a tile thats gonna be his base, then the next one till all players 
  picked. After that comes the Conquer: starting with the same order as base selection: each player pick a tile in order after everyone picked: multiple choiche question - whoever gets it right his nominated 
  tile becomes his - next round we move the order to the left - so the 1st becomes last, 2nd becomes 1st and so on - then same everyone picks - answers - right ones gets the tile - this goes for as many round 
  as we set it when creating the room. After the rounds passed comes the phase: Expansion: We use Estimation questions : whoever gets the closest wins and gets to select a tile - this goes until all tiles are 
  owned by someone. After this comes the phase : Duel - player order the same way as in Phase: Conquer. The player whose turn it is select a tile to attack - it has to be connected to one of his tiles - 
  Multiple Selection question comes - if the attacker gets it right, he takes the tile, if the defender he gets bonus 100 points, if both get it right both get 50 points. This goes until another type of given 
  round count from the room creation, or until only 1 player has a base. Also the base has 3 health, so it has to be succesfully attacked 3 times
